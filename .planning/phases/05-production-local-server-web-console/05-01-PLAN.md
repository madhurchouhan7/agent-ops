  <action>
    Configure production-ready local server runtime and demo orchestration:
    1. In `pyproject.toml`:
       - Add `uvicorn>=0.30` dependency.
       - Define entry point script `agentops = "agent_ops.main:run"` for CLI execution.
    2. In `src/agent_ops/api/app.py`:
       - Enable `CORSMiddleware` (allow all origins, headers, and methods).
       - Determine database URL from `DATABASE_URL` env var, falling back to `sqlite:///agent_ops.db`.
       - Initialize database schema on startup via `init_db(engine)`.
       - Mount static directory `/static` and serve `index.html` at `/` and `/console`.
    3. In `src/agent_ops/api/routes.py`:
       - Implement `POST /v1/demo/triage/start`:
         - Accepts `ticket_id: str`, `message: str`, `customer_id: str`.
         - Initializes run, registers tools in registry.
         - Executes `SupportTriageWorkflow.execute_until_approval`.
         - Pauses at approval gate, returns run response and pending approval.
       - Implement `POST /v1/demo/triage/{run_id}/resume`:
         - Resumes run via `SupportTriageWorkflow.resume_after_approval`.
         - If approved: executes simulated reply, completes `SUCCEEDED`.
         - If rejected: skips reply, completes `CANCELLED`.
         - Returns updated run response.
    4. In `src/agent_ops/main.py`:
       - CLI server runner using `uvicorn.run("agent_ops.api.app:create_app", host="127.0.0.1", port=8000, factory=True)`.
       - Prints rich startup banner with endpoints and clickable console link.
    5. In `tests/integration/test_demo_routes.py`:
       - Test starting triage demo via API pauses at approval gate.
       - Test resuming triage demo with approval succeeds and sends simulated reply.
       - Test resuming triage demo with rejection cancels and blocks reply.
  </action>
  <verify>uv run pytest tests/integration/test_demo_routes.py; uv run mypy</verify>
  <done>
    Server runs with disk persistence and CORS, demo endpoints advance workflow to approval and resume cleanly, and tests pass.
  </done>
