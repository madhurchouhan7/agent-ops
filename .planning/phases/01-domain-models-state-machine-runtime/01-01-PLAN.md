    Implement the in-memory bounded execution runtime:
    1. In `src/agent_ops/runtime/engine.py`:
       - Define `WorkflowNode`: callable protocol or base class taking `(state: dict[str, Any]) -> dict[str, Any]`
       - Class `WorkflowRuntime`:
         - Initializes with workflow graph definition and budget configuration
         - Method `step(run: Run, next_node_id: str, action: Callable[[dict[str, Any]], dict[str, Any]]) -> Step`:
           - Checks wall-clock timeout against `run.created_at` and `run.budget.timeout_seconds`. If exceeded, transitions run to `FAILED` with error `BUDGET_EXCEEDED` and raises `BudgetExceededError`.
           - Checks `run.step_count + 1 > run.budget.max_steps`. If exceeded, transitions run to `FAILED` with error `BUDGET_EXCEEDED` and raises `BudgetExceededError`.
           - Ensures run is `RUNNING` (transitions from `CREATED` to `RUNNING` if first step).
           - Executes node action, updates state, increments `run.step_count`, records `Step`, updates `run.current_node`.
         - Method `pause(run: Run) -> None`: transitions to `PAUSED`.
         - Method `resume(run: Run) -> None`: transitions from `PAUSED` back to `RUNNING`.
         - Method `cancel(run: Run) -> None`: transitions to `CANCELLED`.
         - Method `complete(run: Run) -> None`: transitions to `SUCCEEDED`.
    2. In `tests/unit/test_runtime_budgets.py`:
       - Test that runaway loops exceeding `max_steps` immediately halt and mark run as `FAILED`.
       - Test that wall-clock timeout breaches immediately halt and mark run as `FAILED`.
       - Test that paused runs cannot execute steps until resumed.
       - Test full happy path execution from `CREATED` -> `RUNNING` -> `SUCCEEDED`.
  </action>
