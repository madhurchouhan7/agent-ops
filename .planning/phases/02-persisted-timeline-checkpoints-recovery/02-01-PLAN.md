           - Persists current `run.state` into `checkpoints` table with given sequence number.
         - Method `get_latest_checkpoint(session: Session, run_id: str) -> CheckpointModel | None`:
           - Fetches the highest `sequence_no` checkpoint for `run_id`.

       - Class `RecoveryService`:
         - Method `recover_run(session: Session, run_id: str) -> Run`:
           - Loads run record from database.
           - If run status is in `TERMINAL_STATUSES`, raises `TerminalStateError`.
           - Queries latest checkpoint. If found, restores `run.state` and sets `run.current_node`.
           - Appends a `run.recovered` event to `run_events`.
           - Reconstructs and returns a fresh domain `Run` ready to resume execution in `WorkflowRuntime`.

       - Simulate a process crash mid-workflow: initialize run in process A, execute 2 steps, save checkpoint, discard in-memory runtime.
